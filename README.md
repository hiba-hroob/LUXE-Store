# 🛍️ LUXE Store

**LUXE Store** is a full-stack e-commerce web application developed as a freelance project for a real client.

The project focuses on building a modern and user-friendly shopping experience by combining front-end development, server-side logic, database integration, and web application deployment.

## 🏗️ Application Architecture

LUXE Store follows the **Model-View-Controller (MVC)** architectural pattern provided by ASP.NET Core MVC.

* **Models:** Represent the application's data.
* **Views:** Use Razor to render the user interface.
* **Controllers:** Handle incoming requests and coordinate application logic.
* **Entity Framework Core:** Provides database access and manages schema changes through migrations.
* **SQLite:** Stores application data in a relational database.
